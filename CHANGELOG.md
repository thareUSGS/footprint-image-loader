# Changelog

## 0.4.0 - 2026-10-24

- Renamed the plugin to LIFT - Load Image From Footprint.
- Updated plugin packaging and release assets to use the `lift` name.

## 0.3.0 - 2026-10-22

- Place the image group at the top of the layer list, moving an existing group there before loading images.

## 0.2.0 - 2026-10-22

- Updated plugin metadata and version information.
- Clarified the filename or HTTPS field and marked the local directory and HTTPS base URL as optional in the dialog.
- Updated the README to describe filename and URL attributes and the configurable image group name.
- Added sample QGIS project and GeoPackage data under `data/`.
